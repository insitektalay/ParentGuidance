Fix framework generation for dynamic guidance structure mode

Previously, framework generation failed when users had "Dynamic Structure" selected in settings because it was looking   for [SITUATION] sections that only exist in "Fixed Structure" mode. Dynamic mode uses AI-generated section headers   instead.

Modified FrameworkGenerationService to:
- Check if dynamic structure mode is enabled via GuidanceStructureSettings
- Use complete guidance content for dynamic mode instead of extracting sections
- Preserve existing behavior for fixed structure mode
- Include original situation context (title + description) with guidance

Also simplified framework prompt formatting to only pass the framework name instead of name + notification text, reducing    token usage and allowing more flexible AI interpretation.
