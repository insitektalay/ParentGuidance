Add delete functionality to situation cards in library view
Implemented a visible trash icon on each situation card that allows users to delete situations and their associated data.
The delete operation properly handles cascade deletion of related records (guidance, insight_bullet_points, contextual_insights) while respecting foreign key constraints.
Key changes:
- Added trash icon button next to favorite star in SituationCard component
- Updated ConversationService.deleteSituation() to delete related records in correct order
- Added ConversationError enum for better error handling and user feedback
- Enhanced LibraryViewController with delete error alerts
- Provided SQL DELETE policies for situations, guidance, insight_bullet_points, and contextual_insights tables
The implementation ensures data consistency by deleting child records before parent records and provides clear error messages to users when deletion fails.
