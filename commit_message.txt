Add comprehensive prompt logging and simplify framework integration

Added detailed logging throughout the guidance generation pipeline to debug framework integration issues. Modified   framework formatting to pass only the framework name instead of full notification text to reduce token usage and allow   more flexible AI interpretation.

Changes:
  - Added complete prompt logging in Edge Function with clear visual markers
  - Enhanced EdgeFunctionService with framework formatting verification
  - Updated GuidanceGenerationService with detailed variable logging for direct API path
  - Simplified formatFrameworkForPrompt/Request methods to return only framework name
  - Updated prompt template integration to use framework as background context rather than explicit instruction

The logging now shows exactly what prompt gets sent to the LLM, making it easier to debug dynamic vs fixed structure mode  issues and verify proper framework integration.
