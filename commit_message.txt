Add delete/restore functionality to all regulation insight categories

Extended the existing soft-delete archive system from coping strategies to cover all regulation insight categories
(Emotional Self-Regulation, Attention & Focus Patterns, and Flexibility & Social Understanding).

Key changes:
- Created three new archive database tables with RLS policies
- Added Swift models for each deleted insight type with UUID normalization
- Extended ContextualInsightService with 9 new archive/restore methods
- Built complete UI flows: archive views, card components, and navigation
- Added 22 localization keys following semantic structure
- Updated RegulationCategoryView to show archive links for all categories

Users can now safely delete insights from any category knowing they can be restored from the archive if needed. Maintains
consistent UX patterns across all regulation insight types.
