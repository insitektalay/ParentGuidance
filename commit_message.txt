Add deleted coping strategies archive and recovery system

Implement comprehensive archive system for deleted coping strategy cards to prevent accidental data loss and enable
recovery. When users delete coping strategies in the Library section, items are automatically saved to a new archive
table before deletion, allowing users to browse and restore them later.

Key features:
- Database: Created deleted_coping_strategies table with proper RLS policies
- Swift Model: Added DeletedCopingStrategy with conversion utilities
- Service Layer: Enhanced ContextualInsightService with archive, restore, and permanent delete operations
- UI Components: Built DeletedCopingStrategiesView and DeletedCopingStrategyCard with restore/delete actions
- Navigation: Added "View Deleted Items" link in Coping Strategies section
- Error Handling: Comprehensive logging and UUID case sensitivity fixes

Users can now safely delete coping strategies knowing they can recover them through the "View Deleted Items" interface,
with options to restore to active use or permanently remove from archive.
